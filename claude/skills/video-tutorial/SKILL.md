# 영상 자료화 (Claude판)

영상 전체에서 독자가 이해하거나 따라 할 결과를 정하고, 설명에 필요한 장면을 찾아 한국어 튜토리얼로 만든다. 영상 주제와 출력 양식은 사용자의 요청에 맞춘다. 이 플러그인의 MCP 도구(`video-tutorial` 서버)를 사용한다.

## 시작 전 확인

- `check_dependencies`로 ffmpeg, ffprobe, yt-dlp, powershell을 찾을 수 있는지 확인한다. 없으면 설치 방법을 안내한다.
  - Node.js 22 이상(`winget install OpenJS.NodeJS.LTS`), FFmpeg(`winget install Gyan.FFmpeg`), yt-dlp(`winget install yt-dlp.yt-dlp`)
  - PATH에 없으면 `VIDEO_TUTORIAL_FFMPEG`, `VIDEO_TUTORIAL_FFPROBE`, `VIDEO_TUTORIAL_YT_DLP` 환경 변수에 실행 파일 절대 경로를 넣을 수 있다.
- 결과를 저장할 Obsidian Vault 경로를 사용자에게 확인한다. 지정하지 않았으면 묻는다. 임의의 Vault에 저장하지 않는다.

## 원본 확보

- YouTube 주소는 `inspect_youtube`로 실제 다운로드 후보 해상도와 자막 종류를 확인한다. 현재 요청에서 정한 화질을 사용한다. 화질이 미정이면 후보를 먼저 알려 주고 고르게 한다.
- 선택한 화질과 자막 정보로 `download_source`를 호출한다. 자막은 사람이 올린 원어 자막 → 자동 생성 원어 자막 순으로 고른다. 요청한 해상도나 자막을 받지 못하면 실제 오류를 알리고 사용 가능한 선택지를 제시한다.
- 유튜브가 요청을 막으면(429, 봇 확인) 그 사실을 알리고, video-timestamp-analyzer 플러그인의 youtube-summary 스크립트(`--cookies-from-browser`)로 자막만 따로 받는 방법을 안내한다.
- 제공받은 PC의 영상과 SRT는 `import_source`로 등록한다. 자막을 확보할 수 없으면 사용자에게 알린다.

## 영상 타임스탬프 분석기 사용

- 분석을 시작할 때 **video-timestamp-analyzer 플러그인의 `video-timestamp-analyzer` 스킬**을 불러와 그 지침과 선택한 분석 양식의 참고 파일을 읽고 적용한다. 분석 설정(양식·글 길이)은 현재 요청에서 확정한 값으로 진행하고, 빠진 값은 분석기의 선택 절차에 따라 고른다. 출력은 이 플러그인이 만드는 Obsidian 노트로 정해진 것으로 본다.
- 분석기 플러그인이 설치되어 있지 않으면 그 상태를 알리고 설치 명령을 안내한다. 사용하지 않았는데 사용했다고 보고하지 않는다.
  `/plugin install video-timestamp-analyzer --marketplace tlatndms2-droid/video-timestamp-analyzer`
- `read_source_subtitles`로 원문과 원본 시각을 끝까지 읽는다. 발화나 화면이 근거인 부분과 분석자의 설명을 명확히 구분한다.
- 절마다 독자의 질문, 필요한 조작이나 주장, 보여 줄 결과를 한 문장씩 적는다. `make_capture`로 후보 시각과 전후 화면을 확인해 실제 제목·값·대상·결과가 설명에 맞는지 대조한다.
- 자막은 원본 발화에 맞춰 한국어로 옮긴다. 영상 속 메뉴 이름과 숫자는 원문과 대조한다. 자동 생성 자막의 고유명사 오인식(예: Blender → "브렌다")은 화면과 문맥으로 바로잡는다. 설명에 덧붙인 해석은 본문에 두고 발화 자막에는 원본에 있는 의미만 담는다.

## 클립과 시각 자료 만들기

- 클립은 대상과 초기 상태를 식별할 수 있는 시각에 시작한다. 조작이 끝난 뒤 화면의 결과를 읽을 수 있는 순간까지 남긴다. 목표가 바뀌면 다음 절로 나누고, 원인과 결과에 필요한 흐름은 같은 구간에 둔다.
- `make_subtitled_clip`에 원본 기준 시작·끝과 한국어 자막 큐를 밀리초 단위로 전달한다. 도구가 자막을 구간에 맞춰 자르고 첫 프레임 기준으로 옮긴 뒤 영상에 입힌다.
- 화면 한 장으로 읽을 수 있는 메뉴·값·형태는 `make_capture`를 사용한다. 가장 잘 보이는 프레임과 확대 영역을 고른다. 화살표는 방향이나 누를 곳, 원·박스는 차이와 읽을 영역, 글은 확인할 내용과 이유를 나타낸다. 확대 후 위치를 알기 어려우면 원본과 확대 화면을 함께 둔다.
- 전후 차이가 설명의 핵심이라면 2개 프레임을 지정하고 같은 구도·배율·기준을 맞춘다. 두 상태의 이름을 적고 바뀐 위치를 표시한다. 결과 이미지(미리보기)를 직접 보고 가독성과 주석 잘림을 확인한다.
- 짧은 이동·변형 자체를 반복해서 봐야 할 때 `make_motion_gif`에 출발과 도착이 보이는 구간을 지정한다. 설명에 필요한 영역만 자를 수 있다.

## Obsidian 문서 조립

- `assemble_tutorial`에 분석 본문, 클립, 캡처, 필요할 때 움짤을 전달한다. 한 절 안에서 원본 시각과 **한국어 자막 클립 → 설명과 주석 캡처 → 필요한 움짤 → 확인할 결과** 순서로 보여 준다. 원본 시각 링크는 분석기와 같은 `&t=총초#t=표시시간` 형식으로 들어간다.
- 사용자가 지정했거나 사용을 승인한 Obsidian Vault에 `save_to_obsidian`으로 새 폴더를 만든다. 동일한 폴더가 존재하면 새 이름을 확인한다.
- 실제로 확인한 링크·파일·프레임·재생 결과만 완료로 보고한다. 작업 임시 폴더(`%LOCALAPPDATA%\Claude\VideoTutorial\jobs`)는 자동 삭제하지 않는다.
- 영상과 자막의 이용 권리는 사용자가 확인해야 한다는 점을 필요할 때 알린다.
